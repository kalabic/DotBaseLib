# `DotBase.Buffers.Integral.Internal`

Internal ring storage, validation, operations, and implementation bases used by `IntegralRingBuffer`.

Endian-specific concrete ring implementations live in
`DotBase.Buffers.Integral.Internal.Endian`. Scalar endian codecs live separately
in `DotBase.Integral.Internal`.

These namespaces are not public API.
